## 📌 Main Projects (주요 프로젝트)

### 1. 스마트팜 IoT 환경 제어 및 무선 모니터링 시스템
- **개요**: ESP32 마이크로컨트롤러 기반 실시간 센서 수집 및 자동 환기 팬 제어 시스템
- **기간**: 2025.09 ~ 2026.12 (교내 CRC 동아리)
- **담당 역할**:
  - ESP32 메인 제어기 회로 구성 (MH-Z19C CO2 센서, TP4056, 18650 배터리, 4채널 릴레이 모듈 연동)
  - 임계값 기반 Fan 자동 제어 알고리즘 및 VS Code 기반 웹 인터페이스 연동
- **문제 해결 (Troubleshooting)**:
  - 센서 데이터 신호 노이즈 발생 시 데이터 필터링 알고리즘 적용 및 회로 보완을 통해 측정이 안정화되도록 해결

### 2. ROS 2 기반 자율주행 및 시뮬레이션 환경 구축
- **개요**: LiDAR 센서와 Gazebo 시뮬레이터를 활용한 TurtleBot3 자율주행 프로젝트
- **기간**: 2026.06 ~ 2026.07 (AX로보틱스 부트캠프)
- **담당 역할**:
  - ROS 2(Humble) 노드 간 Topic(Pub/Sub) 및 Service 통신 체계 구현
  - LiDAR 센서 데이터를 수집하여 2D Grid Map 작성(SLAM) 및 위치 추정(Localization) 수행
  - Gazebo 3D 시뮬레이션 환경에서 경로 생성 및 가상 기체 모션 제어 검증
