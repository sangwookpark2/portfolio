# 🌿 ESP32 기반 스마트팜 환경 제어 및 무선 모니터링 시스템

- **개발 기간**: 2025.09 ~ 2025.12 (CRC 학과 동아리 프로젝트)
- **개발 환경**: VS Code (PlatformIO / C++), HTML5, CSS3, JavaScript
- **사용 하드웨어**: ESP32, MH-Z19C CO2 센서, TP4056 충전 모듈, 18650 리튬이온 배터리, 4채널 릴레이 모듈, 환기 Fan
- **주요 기능**: 실시간 CO2 농도 측정, 임계값 기반 Fan 자동 제어, Wi-Fi 무선 웹 모니터링 및 수동 제어

---

## 📌 프로젝트 개요

온실 및 스마트팜 내부의 이산화탄소(CO2) 농도를 실시간으로 계측하여, 지정된 임계치를 초과할 경우 환기 Fan을 자동으로 구동하는 **ESP32 기반 IoT 환경 제어 시스템**입니다. 

배터리 전원 관리부터 센서 데이터 수집, 릴레이 모듈 제어, 무선 웹 인터페이스 연동까지 임베디드 하드웨어와 소프트웨어 전 과정을 직접 구축했습니다.

---

## 🛠️ 하드웨어 구성 및 회로 설계

* **메인 컨트롤러**: ESP32 (Wi-Fi/Bluetooth 지원 마이크로컨트롤러)
* **전원부**: TP4056 충전 모듈 + 18650 리튬이온 배터리 (단독 전원 공급 및 충전 회로 구성)
* **센서부**: MH-Z19C NDIR CO2 센서 (UART 통신 방식 데이터 수집)
* **구동부**: 4채널 릴레이 모듈 (환기 Fan 및 부가 장치 제어)

---

## ⚙️ 주요 개발 내용

### 1. ESP32 펌웨어 및 제어 로직 구현 (C/C++)
- UART 통신을 이용한 MH-Z19C CO2 센서의 실시간 농도(PPM) 데이터 수집 및 파싱
- CO2 측정값에 따른 4채널 릴레이 제어 GPIO 로직 구성 (지정 PPM 초과 시 환기 Fan 자동 ON/OFF)

### 2. VS Code 기반 웹 인터페이스 및 무선 통신 구축
- ESP32 내부 웹 서버(Web Server) 구축 및 스마트폰/PC 웹 브라우저 접속 환경 구현
- 센서 측정값을 실시간으로 표시하고, 웹 화면에서 환기 Fan 및 릴레이 각 채널을 수동으로 조종할 수 있는 커스텀 UI 설계

## 🎯 핵심 트러블슈팅 (Troubleshooting)

* **문제 현상**: 센서 데이터 측정 도중 원인을 알 수 없는 신호 노이즈가 발생하여, 릴레이 및 Fan 제어 로직에 불확실성(오동작) 유발.
* **원인 분석**: 
  1. 소프트웨어 측 데이터 처리 단계에서의 노이즈
  2. 전원부 및 회로 결선 상의 물리적 유입 노이즈로 원인을 구분하여 다각도로 검증.
* **해결 방법**: 
  - **소프트웨어**: 센서 수집 데이터에 데이터 필터링 알고리즘을 적용하여 바운싱 피크값 제거.
  - **하드웨어**: 전원선 및 센서 회로의 디커플링/보완을 진행하여 신호의 물리적 안정성 확보.
  - **결과**: 노이즈를 제어하고 센서 측정값을 안정화하여 릴레이 오동작 문제 완벽 해결.
