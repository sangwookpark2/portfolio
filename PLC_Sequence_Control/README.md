# ⚡ MELSOFT GX Works2 기반 PLC 래더 로직(Ladder Logic) 및 자동화 제어 실습

- **교과목명**: 스마트팩토리 PLC (캡스톤디자인)
- **개발 환경**: MELSOFT GX Works2, QCPU (MELSEC-Q 시리즈)
- **사용 언어**: LD (Ladder Diagram, 래더 프로그래밍)
- **주요 내용**: 자기유지, 시간지연, 인터록, 타이머/카운터 응용, 산술연산, 특수기능 타이머(STMR), 인덱스 레지스터 및 데이터 정렬 알고리즘 구현

---

## 📌 개요 및 실습 배경

산업용 자동화(FA) 및 스마트팩토리 제어의 핵심인 **PLC(Programmable Logic Controller)의 동작 원리와 레더 프로그래밍(LD)**을 습득하고, 시퀀스 제어 기초부터 데이터 연산 및 정렬 알고리즘까지 단계별 실습을 수행했습니다.

---

## 🛠️ 주요 실습 및 제어 로직 구현 내용

### 1. 시퀀스 기초 제어 회로 (Sequence Logic)
- **자기유지 회로 (Self-Holding Circuit)**: ON 우선 및 OFF 우선 자기유지 회로를 작성하여 타워램프 점등/소등 제어 구현
- **인터록 회로 (Interlock Circuit)**: 
  - **선입우선 회로**: 모터 정/역전 구동 시 중복 신호 유입으로 인한 쇼트 및 오동작 방지 (상대 내부 코일 직렬 연동)
  - **후입우선 회로**: 스위치 입력 시 이전 동작을 차단하고 최신 명령을 우선 처리 (상대 내부 코일 병렬 연동)
- **비상정지 회로 (Emergency Stop)**: 비상정지 스위치 신호 입력 시 최우선 순위로 모든 출력을 즉시 소등/정지시키는 안전 제어 기법 적용

### 2. 타이머 & 카운터 응용 제어 (Timer & Counter)
- **시간 지연 회로**: 저속 타이머(100ms) 및 고속 타이머(10ms)를 이용한 온 딜레이(On-Delay) / 오프 딜레이(Off-Delay) 타워램프 점등 제어
- **적산 타이머(ST) 및 플립플롭(FF)**: 전원 전압/입력이 꺼져도 현재값을 유지하는 적산 타이머와 1개 버튼으로 ON/OFF 상태를 전환하는 토픽/토글 스위치 회로 구성
- **클럭 펄스(Clock Pulse) 생성**: 타이머 2개(T0, T1)를 상호 리셋 구조로 결합하여 지정된 비율(예: 0.8초 ON / 0.2초 OFF)로 점멸하는 클럭 펄스 신호 생성
- **특수기능 타이머(STMR)**: `STMR` 명령어를 활용하여 1개의 타이머로 OFF Delay, OFF One-Shot, ON One-Shot, ON/OFF Delay 4가지 출력 접점을 분기 처리
- **가감산 카운터(UDCNT1/UDCNT2)**: 1상 및 2상 입력 기반 업/다운 카운터를 구동하여 센서 입력에 따른 수량 가산/감산 로직 작성

### 3. 산술연산 및 데이터 제어 응용 (Arithmetic & Data Control)
- **비교 연산자 (`=`, `<`, `>`, `<=`, `>=`)**: 타이머 및 카운터 계측값 비교를 통한 구간별 램프(빨강/주황/초록) 순차 점등 및 자동 반복 시퀀스 설계
- **주차장 차량 수 관리 시스템**: 입구/출구 센서 신호(X0/X1) 및 `+P`/`-P` 산술 연산 명령을 연동해 잔여 주차 가능 대수 계산 및 만차 표시 제어
- **스톱워치 프로그램**: 
  - 1초 클럭 특수 릴레이(`SM412`) 및 나눗셈(`/`) 연산자 나머지를 활용해 시:분:초 변환 알고리즘 구성
  - 24시간 ↔ 12시간 AM/PM 표기 모드 전환 기능 구현
- **데이터 이동 명령 (`MOV`, `BMOV`, `FMOV`, `$MOV`)**:
  - 가공 부품(A, B, C) 선택 스위치에 따른 가공 시간 타이머 설정값(`D100`) 가변 제어
  - 비트 분할 전송(`K4Y20`)을 활용한 무대 조명 및 램프 다중 묶음 일괄 제어
  - ASCII 코드 포맷 문자열 전송 및 터치패널(HMI) 상태 메시지 출력 모듈 구성

### 4. 고급 알고리즘 (인덱스 레지스터 & FOR~NEXT)
- **인덱스 레지스터(`Z0~Z19`) 간접 참조**: 디바이스 포인터 기능을 활용하여 연산 주소 동적 할당
- **FOR~NEXT 중첩 루프 기반 최댓값 내림차순 정렬**:
  - 이중 `FOR~NEXT` 반복문과 `Z0`, `Z1` 인덱스 레지스터를 조합하여 10개 데이터(`D10~D19`) 중 최댓값을 실시간으로 탐색해 `D200~D209` 영역에 내림차순으로 정렬하는 데이터 처리 로직 완성
- **3자리 비밀번호 인증 프로그램**: `SM402`(Initial Scan) 및 펄스화 명령어(`MOVP`, `+P`)를 적용해 설정된 비밀번호('213') 입력 시에만 초록등(승인)이 점등되고, 오입력 시 빨강등(경고)이 점등되는 시스템 구현
